# EV charging installation (UK) — industry report

Snapshot: regulated, must-be-electrician work; homeowner stuck without one. One job
type (domestic 7kW) + one geography = the acquisition wedge. See NEW_SPARKY_STACK.md.

## Legislation that shapes the product

| Law / instrument | Requirement | Product implication |
|---|---|---|
| Building Regulations 2010, Part S + Approved Document S (England, from 15 Jun 2022) | New builds / major renovations / change-of-use must provide charge points or cable routes | New-build estates = bulk lead source; agent asks "new build?" to route correctly. |
| Electric Vehicles (Smart Charge Points) Regulations 2021 (SI 2021/1467, in force 30 Jun 2022, GB) | Private chargers must have smart functionality, DSR capability, off-peak defaults (not 8-11am/4-10pm weekdays), random delay, safety-over-override, usage metering, statement of compliance; sellers keep 10-yr register | Product graph lists ONLY compliant chargers; agent explains off-peak defaults + random delay as features (callers report them as faults!); never recommend non-compliant units. |
| BS 7671 Section 722 | EV supply equipment rules (RCD, earthing, PME/PEN-fault protection) | Survey checklist includes earthing/PME questions; three-phase always human survey. |
| Part P (as electrical.md) + DNO notification | Notifiable work; DNO connect-and-notify or prior approval; 60A/looped supplies may need fuse upgrade | Agent never promises dates where DNO/fuse upgrade involved; tracks DNO status per job. |
| OZEV EV chargepoint grant (£350; renters/flats/dedicated parking — rules change) | Eligibility-gated subsidy, NOT a right | Agent states current rule from graph, never guarantees; eligibility check via survey. |
| ETSI EN 303 645 (via Smart Charge Points Sch 1) | Cyber-security baseline for the charger itself | Prefer chargers with documented compliance; WiFi/signal survey question doubles as security posture check. |

## Demand drivers
Second-hand EV boom (buyers need home charging), new-build Part S estates, OZEV grant
windows, Octopus-style tariffs (Ohme pairing), solar+battery pairing (zappi). Fault
aftercare (tripping, schedules, red lights) is the retention loop — most "faults" are
settings; free-checks-first keeps trust and callouts for real work.
