# LenoChat — brief (source: lenochat.com/solutions/ecommerce, fetched 2026-09-10)

Sydney, founded 2025. Positioning: TEAM inbox first, AI second (vs agent-first rivals).
Copilot drafts + agent auto-answers FAQs; humans keep send control.

## What it does
- Unified inbox: WA + IG + Messenger + website chat; Shopify orders/shipping/product in the
  same window; assignments, internal notes, roles, history; iOS/Android apps (van-friendly).
- Workflows: checkout-hesitation recovery, order/return resolution, social-DM → repeat
  purchase; ad-context attached to IG ad DMs; 14-language auto-detect + translate.
- Catalog-aware AI (live stock/price/variants, cross-sell on cart), trained on help
  center + policies in brand tone, overridable per message.

## Tech pattern to steal
Human-in-the-loop default (draft-first, agent only on trained FAQs) = exactly our sparky
morning-queue posture; phone apps for road workers; "different from Shopify Inbox" page =
positioning template (Shopify Inbox only covers Shopify channels; same true for us vs
generic bots). GDPR/SSL/99.9% badges as checklist.
