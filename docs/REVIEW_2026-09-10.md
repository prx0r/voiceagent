# Review — where we are (2026-09-10)

## What this is
Graph-grounded voice + messaging agent for UK trade businesses (wedge: electricians,
EV chargers, after-hours calls). Kernel decides from verified state; channels render;
every side effect is approval-gated; every contact becomes a case. 30/30 tests green.
Uncommitted work below is the entire sparky vertical — nothing pushed yet.

## Built and working (verified live, not just unit-tested)
- Kernel: graph retrieval + LLM wording + output guard + tiered tools + case files.
- EV business pack: 19-node VoltLine graph (5 chargers, pricing ranges, OZEV/DNO/cert
  policies, safety escalation); retrieval probes all hit correct nodes.
- Homeowner funnel (/quote): postcode + 3 photos → qualify score → idempotent survey
  booking → case + ticket. Retry-safe, rejects empties.
- After-hours loop (/calls/intake → /sparky): transcript → triage (wake/queue) →
  morning digest with slots, draft reply, quote range, worth-it score, parts check.
  Urgent 2am test wakes; routine 11pm test queues with 08:00 slots.
- Sparky app (/sparky): overnight queue + one-click book/reply/approve-parts/on-my-way/
  log-time/close-case + personalised job feed + CSV export for the accountant.
- Tradie brain: profile (hours/prices/radius/likes), worth-it scoring, quote drafting,
  job-duration stats feeding back into scores.
- Voice adapters: Qwen realtime (corrected protocol), Edge fallback; LLM provider flip
  (Meta Spark/OpenAI/custom via env); per-sparky API keys; retention sweeper
  (dry-run default, opens never swept); UCP profile + CONNECT docs (Muse-ready).

## Decisions taken (and why)
1. Voice = pipeline on LiveKit-on-Telnyx, not Qwen S2S (audit + cost + SIP fit).
2. Target arch = streaming speculative cascade (500-700ms, graph prefetched on partials).
3. WhatsApp = money channel, IG = discovery-only (platform constraint, unanimous).
4. No Marketplace-data dependence; job feed from own funnel.
5. Business-process agent on official APIs only (WA terms allow it; generic assistants
   banned; QR gateways pilot-only). Multi-home WA+SMS+voice+web from day one.
